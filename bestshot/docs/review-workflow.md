# 分類後の選別・並べ替え

## 保存と再開

- 分類結果の上部ツールバーで「作業を保存」を選ぶと、`.bestshot` ファイルに現在の作業を保存できます。
- 読み込み画面右上のフォルダアイコン「選別作業を再開」から保存ファイルを開くと、再解析なしで再開できます。
- 保存対象は分類結果、ベスト指定、選別マーク、保護、確認済み状態、グループ名、仕分け先、削除候補、比較選択、並べ替え、注目中の写真、解析データとサムネイルです。
- **手動保存です。終了する前に保存してください。** 写真本体は含まれません。元写真を移動・削除すると、元画像表示やコピー・移動などを実行できなくなる場合があります。別端末へ保存ファイルだけを移しても写真への参照は引き継げません。
- Androidではファイル選択画面で `.bestshot` を選んでください。独自拡張子の制限を避けるため全ファイルを表示し、読み込み時に形式を検証します。

## 選別・グループ編集

1. 「選別・グループ編集」を開いてグループを展開します。
2. 写真のメニューから「未選別／残す／保留／除外」を指定できます。「除外」はマークであり、ファイルの削除は行いません。
3. 鍵アイコンで保護を切り替えられます。保護した写真は削除・移動から除外されます。コピーは可能です。「残す」「保留」も削除候補にはできません。
4. 写真のチェックボックスで一部を選び「選択写真を分割」。グループ左側のチェックボックスで複数グループを選び「結合」。名前も変更できます。
5. 「確認済み」はAIの「要確認」と独立した作業状態です。メイン画面の「未確認のみ」で未完了グループを絞り込めます。

分割・結合は写真ファイルを変更しません。安全のため対象グループの削除候補と確認済み状態を解除し、以前のAIグループ判定根拠とスコア内訳をクリアします。写真ごとの選別・保護・仕分け先は維持されます。分割時は元のベストを含む側でベスト指定を維持し、もう一方は先頭の写真を仮のベストとします。結合時は先頭グループのベストを維持します。

## 並べ替え

- グループ：撮影日時の古い／新しい順、枚数の多い／少ない順、AI要確認優先。
- 写真：おすすめ順、撮影日時の古い／新しい順、ファイル名の昇順／降順。
- ポートレート：被写体グループ順、顔の写り順も選べます。被写体グループ順は既存グループをまとめて表示する機能で、人物の身元認識を追加するものではありません。
- 顔の写り順は目開きと顔領域の鮮鋭度に基づく目安です。顔検出がない写真は最後になります。
- おすすめ順は解析済み評価スコアを使用します。手動編集でスコアを解除した場合は、グループ内のISO補正済みピント・露出・顔評価から算出します。異なるシーンのスコアを直接比較せず、グループ順を優先します。
- 日時不明の写真は日時の昇順・降順とも最後です。同点はIDで順序を固定します。
- 並べ替えてもベスト指定・削除候補・比較選択は変更しません。現在注目している写真も維持します。シャープネス単独の並べ替えはありません。
- 「選別状態で絞り込み」は、通常モードでは該当写真を含むグループ、ポートレートでは該当写真を表示します。

上部ツールバーが収まらない画面では横にスクロールできます。
