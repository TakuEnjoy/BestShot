# BestShot for iPhone & iPad

連写・類似写真をグループ化し、ピント・露出・顔の表情からベストショットを選別する、iOS／iPadOS専用のFlutterアプリです。最低対応OSは15.5です。

## 機能

- 写真ライブラリと「ファイル」のフォルダーからの取り込み。撮影日選択、並び順、バッチ上限、キャンセル。
- JPEG／PNG／HEIC／HEIFと、埋め込みJPEGを含むRAW画像の読み込み。
- pHash・色分布・ORB・ONNX埋め込みによる類似写真のグループ化。通常／ポートレートモード、連写時間窓、判定根拠表示。
- 鮮鋭度・露出・目の開閉による評価、ベストの手動指定、削除候補の確認。
- 最大4枚のルーペ比較、連動ズーム・パン、フォーカスマスク、ヒストグラム、HUD切り替え。
- グループ・写真の並べ替え、選別マーク・保護・確認済み、グループの分割・結合、作業の保存／再開。詳しくは [選別・並べ替え](bestshot/docs/review-workflow.md)。
- ベストショットの原本書き出し。フォルダー写真のカスタムフォルダーへの移動・コピー。
- ライブラリ写真はPhotoKit経由で削除。フォルダー写真は元のフォルダー内の `BestShot Trash` に退避し、復元可能な状態を維持。
- iPadの縦横表示・分割表示、外付けキーボード、トラックパッド・マウス・Apple Pencilの入力に対応した画面構成。

判定ロジックはv2-redesignの `89d4296` をベースに維持し、`8a503a4` のソート・選別作業機能を統合しています。プラットフォーム依存処理はCore Image、ImageIO、PhotoKit、iOSのセキュリティスコープに統一しています。

## 開発・検証

Mac、Xcode、CocoaPods、Dart 3.11.1以降に対応するFlutter SDKが必要です。

```sh
cd bestshot
flutter pub get
flutter analyze
python3 scripts/run_flutter_tests.py
flutter build ios --release --no-codesign
open ios/Runner.xcworkspace
```

実機実行にはXcodeで開発チームと署名を設定してください。ビルド・権限・復元操作の詳細は [iOSセットアップ](bestshot/IOS_SETUP.md)、判定仕様は [モード別グループ化](bestshot/GROUPING_MODES.md) を参照してください。

外部画像で検証する場合:

```sh
BESTSHOT_TEST_DIR=/path/to/photos python3 scripts/run_flutter_tests.py
```

## iPhone／iPad向けの処理

- インポートは通常2並列、RAWなどの大きな画像は1並列。解析は最大3並列、ONNX推論は8枚単位のバックグラウンド処理。
- 画像キャッシュはiPhoneで96MB、iPadで192MB。分割表示の幅ではなくディスプレイのサイズで判別し、メモリ警告時に解放。
- 画像の向きを補正して顔枠を算出。プレビューと拡大画像の解像度が変わっても顔枠の位置を維持。
- 埋め込みキャッシュを保存。同梱モデルが更新されたときだけモデルファイルを差し替え、同じモデルのキャッシュは維持。
- 写真ライブラリの限定アクセスとiCloud読み込みに対応。iCloudの状態やファイルプロバイダーによる挙動は実機確認が必要。

## キーボード

iPadにキーボードを接続した場合、⌘Oでフォルダー選択、矢印で移動、Space／Dで削除候補、Bでベスト指定、1〜4で比較ペインを選択できます。ルーペではIでHUD、Hでヒストグラム、Mでフォーカスマスク、Sでズーム連動、Zでフォーカス位置への拡大を切り替えます。

## 構成

- `bestshot/ios`: iPhone・iPadの実行ターゲットとネイティブ連携
- `bestshot/lib`: 共通の画像解析・グループ判定・画面とiOSサービス
- `bestshot/assets/models`: 同梱ONNXモデル
- `bestshot/test`: ロジック・UI・iOS連携の回帰テスト
- `bestshot/scripts`: モデル生成とMac上のテスト実行

Mac用ネイティブライブラリは開発時のFlutterテストでのみ使用します。Mac用アプリの実行ターゲットは含みません。外部パッケージの推移的依存には他OS向け実装が含まれる場合がありますが、iOSアプリには対象プラグインだけが登録されます。
